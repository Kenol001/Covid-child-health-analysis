Data

This folder contains the dataset used for the child health SQL analysis project as well as the codebook.The dataset includes variables related to vaccination services, treatment access and provider barriers among children.

Data source- IHME  website : [IHME PREM Child Health COVID-19 Survey 2021](https://ghdx.healthdata.org/record/ihme-data/premise-child-health-covid-19-health-services-disruption-survey-2021) Accessed 2026-03-10
