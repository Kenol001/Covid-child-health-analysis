# Documentation

## Overview

This folder contains the detailed documentation for the **Child Health and Vaccination Analysis** project. The documentation explains the analytical process used to explore vaccination coverage, risk factors, and barriers affecting child vaccination and treatment  in Kenya during covid outbreak.

## Contents

The documentation includes explanations of the SQL queries used in the analysis, summaries of the resulting tables, and interpretations of the findings.

### Files

* **documentation.md** – Provides detailed explanations of each SQL query, the purpose of the analysis, summaries of the results, and key insights derived from the data.

## Purpose

The goal of this documentation is to clearly describe the analytical workflow and make the project easy to understand for anyone reviewing the repository, including recruiters, collaborators, and other data analysts.

## Related Project Sections

* **data/** – Contains the dataset used for the analysis.
* **queries/** – Includes the SQL scripts used to explore and analyze the data.
* **results/** – Contains exported results from the SQL queries.
